# Margonem — Dwarven Forge UI

Production-only CSS skin for the existing Margonem client.

This repository contains only assets intentionally changed by the Dwarven Forge theme, the theme CSS/palette, and implementation documentation. Original Margonem graphics that the theme does not change are not copied here.

The package is CSS-only: it adds no avatars, NPC portraits, new buttons, new data, or other features requiring JavaScript. Dynamic values such as HP, mana, energy, EXP, level, nick, currencies and NPC/quest data remain generated by the game client.

## Structure

- `assets/gui/` — production replacement PNG assets only
- `css/palette.css` — central Dwarven Forge color variables
- `css/dwarven-forge.css` — verified CSS overrides for existing client selectors
- `css/dwarven-forge.bundle.css` — CDN-ready stylesheet entrypoint
- `install/dwarven-forge.user.js` — short userscript used only to load the stylesheet
- `docs/asset-manifest.csv` — manifest of assets intentionally changed by the theme
- `docs/changed-assets.md` — scope note
- `docs/verification.md` — selector verification report against the supplied `style.Bjtb6ElF.css`

## Test installation

Install `install/dwarven-forge.user.js` in Tampermonkey or Violentmonkey and enable it for Margonem. The userscript does not alter game mechanics; it only loads the CSS bundle.

CSS bundle:

`https://cdn.jsdelivr.net/gh/Doiua97/margonem-dwarven-forge-ui@main/css/dwarven-forge.bundle.css`

## Production rules

1. No original Margonem asset is stored here unless it is intentionally replaced by a new Dwarven Forge asset.
2. No dynamic game value is baked into a PNG.
3. The original multipurpose `buttony.png` sprite is not globally replaced. Structural UI regions are overridden selector-by-selector with dedicated assets so semantic client icons remain untouched.
4. The theme uses the original Margonem DOM and mechanics.
