# Margonem — Dwarven Forge UI

Production-only CSS skin for the existing Margonem client.

This repository contains only assets intentionally created for the Dwarven Forge theme, theme CSS/palette, the loader userscript and implementation documentation. Original Margonem graphics that the theme does not change are not copied here.

The package is CSS-only: it adds no avatars, NPC portraits, new data panels or mechanics. Dynamic values such as HP, mana, energy, EXP, level, nick, currencies and NPC/quest data remain generated by the game client and are only repositioned/styled through existing DOM selectors where needed.

## Active version

`v0.3.0` — full-coverage rebuild based on the supplied current client stylesheet and the coverage strategy demonstrated by `podglądowy.css`.

## Active structure

- `assets/gui/v03/` — active v0.3 production PNG assets
- `css/palette.css` — central Dwarven Forge color variables
- `css/v03/core.css` — global windows, controls, inputs, menus and tooltip language
- `css/v03/hud-chat.css` — permanent HUD, bottom panel, chat, character/inventory and minimap
- `css/v03/panels.css` — scrollbars, dialogue, battle and shared panel families
- `css/v03/modules.css` — clan, auctions, depot, shop, premium, matchmaking, achievements, news etc.
- `css/v03/assets.css` — binding of production PNG assets to existing client selectors
- `css/dwarven-forge-v03.css` — v0.3 assembler
- `css/dwarven-forge.bundle.css` — CDN entrypoint used by the loader
- `install/dwarven-forge.user.js` — userscript loader; current version 0.3.0
- `docs/asset-manifest.csv` — active production asset manifest
- `docs/coverage-v03.md` — scope and coverage notes
- `docs/verification.md` — earlier selector verification notes

## Test installation / update

Install `install/dwarven-forge.user.js` in Tampermonkey or Violentmonkey. The script contains explicit `@updateURL` and `@downloadURL` entries and its `@version` is increased when a new test build is ready.

`https://cdn.jsdelivr.net/gh/Doiua97/margonem-dwarven-forge-ui@main/css/dwarven-forge.bundle.css?v=0.3.0`

## Production rules

1. No original Margonem asset is stored just because the client references it.
2. No dynamic game value is baked into a PNG.
3. Native item rarity/highlight rendering is not overridden.
4. Item graphics, skill icons, buffs/debuffs, profession icons, currencies and quest-state data remain client-driven.
5. The theme may redesign and reposition existing UI elements through CSS, but does not create new mechanics or JS-driven panels.
6. `podglądowy.css` is used as a technical coverage reference only; its third-party graphics are not copied.
