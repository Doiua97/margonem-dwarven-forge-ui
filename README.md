# Margonem — Dwarven Forge UI

Production-only CSS skin for the existing Margonem client.

## Repository rule

This repository contains **only**:
- assets intentionally changed by the Dwarven Forge theme,
- the theme CSS and palette,
- implementation documentation.

Original Margonem graphics that the theme does not change are **not copied here**.

## No new mechanics

The package is CSS-only. It does not add avatars, NPC portraits, new buttons, new data,
or any feature that would require JavaScript. Dynamic values (HP, mana, energy, EXP,
character level, nick, currencies, NPC/quest data) remain generated by the game client.

## CSS

Use `css/dwarven-forge.css`. Asset URLs point directly to this GitHub repository.

## Important sprite rule

The original general-purpose `buttony.png` sprite is **not replaced globally**.
It contains many unrelated semantic/game icons. Instead, structural UI parts that used
specific regions of that sprite (HUD frame, bottom panel, close button, battle toggle,
etc.) are overridden with dedicated production assets from this repository.
This avoids corrupting unrelated client icons and preserves existing game behavior.
